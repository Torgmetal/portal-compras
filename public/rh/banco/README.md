# Banco de imagens do RH (artes de vaga)

Fotos de fundo EXCLUSIVAS das artes de recrutamento ("Gerar arte" em `/rh/vagas`).
Separadas de `/public/obras` (que é usada em login, fornecedores e home) — aqui só
entram imagens que fazem sentido para divulgar vagas.

- Referenciadas em `app/rh/vagas/VagasClient.jsx` (lista `FUNDOS_RH`).
- Otimizadas para fundo de canvas 1080×1080 (Feed) e 1080×1920 (Story).
- Para adicionar/trocar: colocar o arquivo aqui e registrar na lista `FUNDOS_RH`.
